## Overview

This repository contains the community health files and organization profile for the **getkist** GitHub organization.

---

## Contents

### Community Health Files

These files are used as defaults for all repositories in the organization:

- `CODE_OF_CONDUCT.md` - Community code of conduct
- `CONTRIBUTING.md` - Contribution guidelines
- `SECURITY.md` - Security policy and vulnerability reporting
- `SUPPORT.md` - Support resources and getting help
- `FUNDING.yml` - Sponsorship and funding information

### Issue & PR Templates

- `.github/ISSUE_TEMPLATE/` - Issue templates for bug reports, feature requests
- `.github/PULL_REQUEST_TEMPLATE.md` - Pull request template

### Organization Profile

- `profile/README.md` - Organization profile displayed on [github.com/getkist](https://github.com/getkist)
